# heraldarr

Announces new media from Sonarr and Radarr to Discord channels friends read: batched per series,
upgrades and repeats suppressed, Components V2 cards with media-server deep links. Go, stdlib first.

## Work loop

1. Your issue names one package; it is yours. Other packages change only through the seams in
   `internal/domain` (types and interfaces). When a seam must change, make the smallest change,
   and call it out at the top of the PR: seam changes merge first and need the maintainer's review.
2. Work test-first. Done = `make check` green (a Stop hook runs it) and your package's parity
   tests un-skipped (`implemented = true`) and passing.
3. Open a PR: `Closes #N`, what changed, and every place the behavior differs from the oracle.

## Parity

The **oracle** is `testdata/expected/`: what the reference implementation (the Python service
this project replaces) did with each scenario in `testdata/scenarios/`. Match it exactly,
as semantically equal JSON. Where the oracle looks wrong, match it anyway and open an issue
labelled `divergence`; parity first, improvements after.

Scenarios are generated by `testdata/harness/build_scenarios.py` and the oracle by `make harness`,
which needs the reference implementation (maintainer's machine). Need a new scenario? Ask in the PR.

## Conventions

- Time comes from `domain.Clock`; logic packages read no wall clock.
- Wrap errors with `%w`; a deleted item is `domain.ErrNotFound`. Log with `log/slog`.
- A new module dependency gets one line in the PR saying why the stdlib isn't enough.
- Test data is fictional: invented titles, `example.org` URLs, placeholder IDs.
- Public destinations show what friends care about (title, scores, links), never paths, sizes or
  release groups: config enforces it, renderers honor `Style.TechDetails`.

## Where things are

- `CONTEXT.md`: the glossary (batch, following, quiet window, route…). Name things with it.
- `docs/adr/`: decisions and their reasons. Read before reversing one.
- `internal/testkit`: scenario loader, fakes for every interface, `StoreContract`.
- `docs/workflow-notes.md`: what we learned running agents on this repo.
